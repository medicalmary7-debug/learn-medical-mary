# Learn Medical Mary

A separate companion landing page for the Medical Mary Circle: an education-led email community for thoughtful wellness information, quality literacy and human-led inquiries.

The site is intentionally static. The email signup form is a privacy-reviewed visual preview only and does not transmit or store visitor details. Before launch, connect it to the selected email provider with separate affirmative consent, unsubscribe handling, retention rules and vendor review.

The existing site at `https://medicalmary.co.za/` and the public repository remain separate and untouched.
