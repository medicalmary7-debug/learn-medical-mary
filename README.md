# Learn Medical Mary

A separate companion landing page for the Medical Mary Circle: an education-led email community for thoughtful wellness information, quality literacy and human-led inquiries.

The site is intentionally static. The Medical Mary Circle signup CTA opens the live Tally form at `https://tally.so/r/xVrGMk`; the website itself does not store submissions. Confirm Tally’s destination, separate affirmative consent, unsubscribe handling, retention rules and vendor review before launch.

The existing site at `https://medicalmary.co.za/` and the public repository remain separate and untouched.
